# Ankit Kumar Singh – Portfolio Website

This repository contains a personal portfolio website for **Ankit Kumar Singh**, a Software Engineer focused on Android platform and system-level development.

## Overview

The site is a static, single-page portfolio built with:

- HTML
- CSS
- Vanilla JavaScript

It highlights:

- Professional introduction
- About section
- Skills
- Projects
- Experience
- Contact information
- Downloadable resume

## Project Structure

```text
.
├── index.html                 # Main page markup
├── style.css                  # Global styling and layout
├── image.jpeg                 # Profile/portfolio image asset
├── AnkitSingh_SE_Resume.pdf   # Downloadable resume
└── js/
    ├── script.js              # Main interactive behavior
    └── script_rem.js          # Additional script file
```

## Run Locally

Because this is a static site, you can run it with any local web server.

### Option 1: Open directly

Open `index.html` in your browser.

### Option 2: Use Python HTTP server

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Customization

To adapt this portfolio for your own use:

1. Update content in `index.html`.
2. Adjust styles in `style.css`.
3. Replace `image.jpeg` and resume PDF with your own files.
4. Update social/profile links and contact information.
